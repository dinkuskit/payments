# Payment setup inside EmDash

DinkusKit Payments connects your DinkusKit Commerce store to Stripe and shows
the payment connection's status in your EmDash admin.

- Connect with your DinkusKit account instead of pasting API keys.
- Set up or resume Stripe onboarding and check the connection.
- Follow the test-order workflow before considering a live launch.

Commerce owns your products, checkout totals and orders. Payments handles the
processor connection. Connect Commerce first, then add Payments to the same
store.

Start with the documented Stripe test workflow. A successful test connection
or test order does not establish live-payment readiness. The plugin, hosted
Payments service and merchant account have separate setup requirements.
