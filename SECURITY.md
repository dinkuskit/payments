# Security

If GitHub shows private vulnerability reporting for this repository, use it.
Until that channel is enabled, contact a DinkusKit maintainer through an
existing private channel. Do not open a public issue containing exploit
details, credentials, API keys, webhook secrets, tokens, payment details, or
customer data. Non-secret production deploy settings may be public; secrets
must remain Cloudflare Worker secrets.

This project is pre-release. No version currently carries a stability or
security-support promise, and no live processor credentials belong in this
repository.
